# LEO-satellite-communication
This is a thesis project on Smooth Handover framework for LEO satellites.


## Project Goals

* Build a basic LEO satellite simulation environment
* Model satellite orbital movement and ground station visibility
* Study satellite-to-ground communication links
* Analyze link availability and Doppler effects
* Model multiple LEO satellites
* Implement and study satellite handover
* Develop a smoother handover framework to reduce link interruption
* Later extend the work towards routing and networking
* And implementation with edge AI/ IOT devices
